Меню и цены

Панель меню

Меняйте названия, описания и цены. Справа внизу сразу видно, как это будет выглядеть на сайте. Готовый файл скачивается кнопкой — им нужно заменить файл в папке data.

Как это работает — коротко:
  1. Поправьте категории и позиции ниже.
  2. Нажмите «Скачать menu.js» — браузер сохранит файл menu.js.
  3. Скачанный файл перенесите в папку data этого сайта и замените старый.
  4. Обновите страницу сайта — меню обновится.

В этом браузере сохранён черновик — можно продолжать с него.

Фото блюд. Положите файл в assets/img/dishes/ и добавьте его имя в data/photos.js — тогда в поле «Фото блюда» появятся подсказки. Фото показывается в блоке «Атмосфера» на сайте, рядом с названием и ценой.

Файл data/menu.js не загрузился. Добавьте категорию вручную или положите файл на место.

Показать текст файла (если скачивание не сработало)

Скопируйте текст, вставьте его в файл data/menu.js и сохраните.

Отзывы гостей

Отзывы на сайте

Здесь можно поправить демонстрационные отзывы, добавить свои и убрать лишние. Готовый файл скачивается кнопкой — им нужно заменить файл data/reviews.js.

Поля «Источник», «Ссылка», «Дата» и «Оценка» пока пустые — заполните их, если появятся настоящие отзывы. Галочка «Демонстрационный» помогает не забыть заменить текст перед сдачей.

Файл data/reviews.js не загрузился. Нажмите «Добавить отзыв» или положите файл на место.

Показать текст файла reviews.js (если скачивание не сработало)

Скопируйте текст, вставьте его в файл data/reviews.js и сохраните.
